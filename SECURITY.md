# Security Policy

## Supported Versions

We actively support and release security updates for the following versions of OpenGNC:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within OpenGNC, please do NOT file a public issue.
Instead, please send an email directly to **batuhanakkova1@gmail.com** with the subject `[SECURITY] OpenGNC Vulnerability Report`.

Please include:
1. A clear description of the vulnerability.
2. Steps to reproduce or proof-of-concept code.
3. Potential impact on simulation integrity, host system, or memory safety (especially regarding C++ native bindings).

You should receive an acknowledgment within 48 hours. We will coordinate a fix and release a patched version promptly.
