class opengnc.fdir.actuator_fdir.UnderactuatedAttitudeController(actuated_axes: tuple[int, int] = (0, 1), kp: float = 0.5, kd: float = 2.0, km: float = 1000.0)[source]

Bases: object

Underactuated Spacecraft Attitude Controller (2-Reaction-Wheel Recovery).

When one or two reaction wheels fail, leaving only 2 functional reaction wheels, full 3-axis instantaneous controllability via wheels alone is lost. This controller stabilizes the two actuated body axes using high-gain PD control and uses auxiliary magnetic torquers (or cross-coupling precession) to asymptotically damp momentum along the unactuated body axis.

Parameters:

  • actuated_axes (tuple[int, int]) – Indices of the two functional body axes (e.g. (0, 1) for X and Y).

  • kp (float, optional) – Proportional attitude error gain. Default is 0.5.

  • kd (float, optional) – Derivative angular rate damping gain. Default is 2.0.

  • km (float, optional) – Magnetic dipole cross-product gain for unactuated axis. Default is 1000.0.

class opengnc.fdir.actuator_fdir.WeightedControlAllocator(b_matrix: ndarray, u_min: ndarray | float = -0.1, u_max: ndarray | float = 0.1)[source]

Bases: object

Dynamic Weighted Control Allocator (WQP / Weighted Pseudo-Inverse).

Maps commanded 3-axis control torque $boldsymbol{tau}_c in mathbb{R}^3$ to actuator commands $mathbf{u} in mathbb{R}^n$ via: $$min_{mathbf{u}} frac{1}{2} mathbf{u}^T mathbf{W}_u mathbf{u} quad text{s.t.} quad mathbf{B} mathbf{u} = boldsymbol{tau}_c$$ subject to $mathbf{u}_{min} le mathbf{u} le mathbf{u}_{max}$.

When an actuator fails, its weight $W_{u, ii}$ is scaled to $infty$ (or its column in $mathbf{B}$ is masked to zero), redistributing torque instantly to remaining functional actuators without perturbing the attitude loop.

Parameters:

  • b_matrix (np.ndarray) – Actuator geometry/effectiveness matrix $mathbf{B} in mathbb{R}^{3 times n}$.

  • u_min (np.ndarray | float, optional) – Minimum torque limit per actuator (N*m). Default is -0.1 N*m.

  • u_max (np.ndarray | float, optional) – Maximum torque limit per actuator (N*m). Default is +0.1 N*m.

class opengnc.fdir.sensor_fdir.ChiSquareMonitor(dim: int, confidence: float = 0.99, window_size: int = 5, persistence_threshold: int = 3)[source]

Bases: object

Statistical Innovation Chi-Square ($chi^2$) Fault Monitor.

Evaluates the Normalized Innovation Squared (NIS): $$gamma_k = mathbf{r}_k^T mathbf{S}_k^{-1} mathbf{r}_k$$ Under the null hypothesis $H_0$ (nominal sensor operation), $gamma_k$ follows a central chi-square distribution with $m$ degrees of freedom, where $m = dim(mathbf{r}_k)$.

Parameters:

  • dim (int) – Dimension of the measurement residual vector ($m$).

  • confidence (float, optional) – Confidence level for the statistical hypothesis test (e.g., 0.99 for 1% $P_{FA}$). Default is 0.99.

  • window_size (int, optional) – Sliding window size for cumulative hypothesis testing. Default is 5.

  • persistence_threshold (int, optional) – Consecutive violations required before triggering a persistent alarm. Default is 3.

class opengnc.fdir.sensor_fdir.GLRTMonitor(dim: int, drift_allowance: float = 0.5, alarm_threshold: float = 5.0, nominal_mean: float = 0.0)[source]

Bases: object

Generalized Likelihood Ratio Test (GLRT) / Page’s CUSUM Drift Monitor.

Detects insidious, low-amplitude sensor drift, temperature ramps, or slow random walks that stay below instantaneous $chi^2$ single-step thresholds.

Evaluates two-sided Cumulative Sum (CUSUM) statistics per channel: $$S_k^+ = max(0, S_{k-1}^+ + r_k - mu_0 - K)$$ $$S_k^- = max(0, S_{k-1}^- - r_k + mu_0 - K)$$

Parameters:

  • dim (int) – Dimension of the monitored signal.

  • drift_allowance (float, optional) – Allowance constant $K$ (slack parameter). Default is 0.5.

  • alarm_threshold (float, optional) – Decision threshold $H$. Default is 5.0.

  • nominal_mean (float, optional) – Expected nominal mean $mu_0$ under $H_0$. Default is 0.0.

Underactuated Spacecraft Attitude Controller (2-Reaction-Wheel Recovery).

When one or two reaction wheels fail, leaving only 2 functional reaction wheels, full 3-axis instantaneous controllability via wheels alone is lost. This controller stabilizes the two actuated body axes using high-gain PD control and uses auxiliary magnetic torquers (or cross-coupling precession) to asymptotically damp momentum along the unactuated body axis.

Parameters:

  • actuated_axes (tuple[int, int]) – Indices of the two functional body axes (e.g. (0, 1) for X and Y).

  • kp (float, optional) – Proportional attitude error gain. Default is 0.5.

  • kd (float, optional) – Derivative angular rate damping gain. Default is 2.0.

  • km (float, optional) – Magnetic dipole cross-product gain for unactuated axis. Default is 1000.0.

Dynamic Weighted Control Allocator (WQP / Weighted Pseudo-Inverse).

Maps commanded 3-axis control torque $boldsymbol{tau}_c in mathbb{R}^3$ to actuator commands $mathbf{u} in mathbb{R}^n$ via: $$min_{mathbf{u}} frac{1}{2} mathbf{u}^T mathbf{W}_u mathbf{u} quad text{s.t.} quad mathbf{B} mathbf{u} = boldsymbol{tau}_c$$ subject to $mathbf{u}_{min} le mathbf{u} le mathbf{u}_{max}$.

When an actuator fails, its weight $W_{u, ii}$ is scaled to $infty$ (or its column in $mathbf{B}$ is masked to zero), redistributing torque instantly to remaining functional actuators without perturbing the attitude loop.

Parameters:

  • b_matrix (np.ndarray) – Actuator geometry/effectiveness matrix $mathbf{B} in mathbb{R}^{3 times n}$.

  • u_min (np.ndarray | float, optional) – Minimum torque limit per actuator (N*m). Default is -0.1 N*m.

  • u_max (np.ndarray | float, optional) – Maximum torque limit per actuator (N*m). Default is +0.1 N*m.
