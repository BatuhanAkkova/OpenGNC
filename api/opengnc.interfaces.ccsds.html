opengnc.interfaces.ccsds.cdm module

CCSDS Conjunction Data Message (CDM) implementation. Standard: CCSDS 508.0-B-1 (Blue Book).

class opengnc.interfaces.ccsds.cdm.CDM(data: dict[str, Any] | None = None)[source]

Bases: object

Conjunction Data Message (CDM) handler.

Supports reading, writing, and analytical collision probability calculation ($P_c$) per CCSDS 508.0-B-1 and Foster (1992) standards.

compute_collision_probability(hard_body_radius: float | None = None) → float[source]

Compute the 2D collision probability ($P_c$) in the encounter frame (Foster, 1992).

Parameters:

hard_body_radius (float, optional) – Combined spherical hard-body radius $R = R_1 + R_2$ (m). If omitted, uses the sum of object1 and object2 radii.

Returns:

Collision probability $P_c in [0, 1]$.

Return type:

float
